# Learning Roadmap

## Goal

Build strong computer science fundamentals, develop practical software engineering skills, and gradually specialize in Artificial Intelligence and Machine Learning.

## Semester 1 — Foundations

- Learn Python fundamentals and problem-solving.
- Practice Linux commands and Bash scripting.
- Understand Git and GitHub workflows.
- Learn HTML and CSS fundamentals.
- Complete the DeveloperPortfolio project.
- Build confidence using APIs and JSON.

## Semester 2 — Core Development

- Study Data Structures and Algorithms.
- Learn SQL and database fundamentals.
- Strengthen programming through regular problem-solving.
- Learn JavaScript and basic web development.
- Complete one relevant technical certification.
- Build at least one small end-to-end project.

## Semester 3 — Exploration

- Study object-oriented programming and advanced DSA.
- Explore AI/ML fundamentals using Python.
- Learn NumPy, Pandas, and data visualization.
- Participate in hackathons and collaborative projects.
- Improve technical documentation and communication.

## Semester 4 Onward — Specialization

- Study machine learning algorithms and mathematics.
- Explore deep learning and neural networks.
- Build projects using real-world datasets.
- Explore research opportunities and internships.
- Contribute to open-source projects.
- Prepare for technical interviews and higher-level opportunities.

## Long-Term Objectives

- Develop a strong GitHub portfolio.
- Participate in competitive programming and hackathons.
- Earn relevant certifications.
- Gain internship and research experience.
- Build projects demonstrating problem-solving and engineering skills.
